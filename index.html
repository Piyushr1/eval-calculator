How this is calculated
  • The grader's observed pass rate is f + J × true accuracy, where f is the share of incorrect answers it passes and J = (share of correct answers it passes) + (share of incorrect answers it fails) − 1. The true gap shrinks by a factor of J.
  • Separate questions: a two-proportion normal approximation, using the pass rates the grader will report.
  • Same questions: McNemar's test, using the observed disagreement after grader mistakes. Mistakes on the same question can be independent or shared; shared mistakes create no fake disagreement.
  • Mistakes are assumed to be random and to treat both versions the same. If your grader favors one version, more questions won't fix it: audit and correct the grader first.
  • Error rates are treated as known. If you estimated them from a small audit, the true requirement could be noticeably higher or lower.
